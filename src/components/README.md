# 📁 components

Composants globaux et réutilisables dans tout le projet.

### Sous-dossier `ui/`

Ce dossier suit une logique de **Design System** :
- Boutons (`Button.tsx`)
- Champs (`Input.tsx`)
- Modaux (`Modal.tsx`)
- Cartes (`Card.tsx`)
- Etc.

🧠 Bonnes pratiques :
- Un composant par fichier.
- Tous les composants sont typés (`React.FC<Props>`).
- Pas de logique métier ici.
